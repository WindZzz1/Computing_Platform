# OBE 功能演示数据准备与说明

本文档用于课堂演示前统一准备数据和讲解口径，帮助演示人员把“页面功能”和“OBE 达成度计算逻辑”串成一条完整业务链路。

## 1. 演示目标

本次演示建议围绕一条主线展开：

```text
基础数据准备 -> 宏观支撑矩阵 -> 课程大纲配置 -> 成绩导入 -> 课程级计算 -> 专业级计算 -> 报表查看与导出
```

核心说明：

- 毕业要求：专业认证中要求学生毕业时应具备的能力，例如工程知识、问题分析、方案设计。
- 指标点：毕业要求的进一步拆分，例如 1.1、2.1、3.1。
- 课程目标：某门课程希望学生达成的学习目标，例如 CO1、CO2、CO3。
- 考核点：支撑课程目标的考试、作业、实验等评分项，例如 AP1、AP2。
- 课程级达成度：基于某个教学班的成绩，计算课程目标和指标点达成情况。
- 专业级达成度：汇总专业下多门课程的课程级结果，计算专业毕业要求指标点整体达成情况。

## 3. 前端演示流程

### 3.1 登录

建议先说明：前端已经对接后端登录接口，登录成功后根据后端返回的角色信息展示不同菜单和权限。

### 3.2 基础数据管理

演示内容：

- 学院、专业、学年学期维护。
- 课程库维护和批量导入。
- 学生库维护。
- 毕业要求和指标点维护。

讲解口径：

基础数据是 OBE 计算的统一数据源，后续所有计算都依赖这些数据。没有课程、专业、指标点和学生数据，后面的矩阵配置、成绩导入和达成度计算都无法完整执行。

### 3.3 矩阵配置

演示内容：

- 选择专业。
- 配置课程对毕业要求指标点的支撑权重。
- 检查列合计是否满足要求。

讲解口径：

宏观支撑矩阵回答的是“哪些课程支撑哪些毕业要求指标点”。专业级达成度计算时，会根据这个矩阵把多门课程的结果汇总到专业指标点上。

### 3.4 课程大纲管理

演示内容：

- 选择课程。
- 配置课程目标。
- 配置内部贡献权重。
- 配置考核点。

讲解口径：

课程大纲回答的是“课程内部如何证明目标达成”。课程目标和考核点建立关系后，成绩才能从原始分数转换成课程目标达成度和指标点达成度。

### 3.5 成绩管理与计算

演示内容：

- 创建或选择教学班。
- 下载成绩模板。
- 导入学生成绩。
- 查看成绩预览。
- 触发课程级计算。

讲解口径：

成绩是达成度计算的数据来源。系统会把学生在各考核点上的得分按课程目标、指标点和权重进行汇总，形成课程级达成度结果。

### 3.6 专业级计算

演示内容：

- 选择专业、学年学期和年级。
- 查看专业看板课程准备状态。
- 执行专业级计算。
- 查看专业级指标点达成度图表。

讲解口径：

专业级达成度不是单门课的结果，而是将该专业多门课程的课程级结果进行汇总，用于判断学生群体是否满足毕业要求。

### 3.7 报表与导出

演示内容：

- 查询课程报表。
- 查看课程目标、指标点、学生成绩明细。
- 导出 Excel 或 PDF。

讲解口径：

报表模块用于沉淀计算结果，方便教学改进、课程归档和专业认证材料整理。

## 4. 演示注意事项

- 演示前先确认后端服务、数据库和 Nginx 代理正常。
- 登录账号应使用后端真实账号，避免使用本地 mock 口径讲解。
- 如果某些模块仍使用 mock 数据，应主动说明“该模块展示前端交互形态，后续可继续接入真实接口”。
- 课程级计算前需要先准备课程目标、考核点、成绩数据。
- 专业级计算前需要保证专业下至少有一批课程级计算结果。

## 5. 一句话总结

本系统通过“基础数据统一维护、课程大纲建立评价关系、成绩导入形成原始数据、课程级和专业级逐层计算”的方式，为工程教育认证中的毕业要求达成度评价提供可视化、可追溯的前端操作入口。
