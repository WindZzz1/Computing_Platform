## 📊 计算公式说明

### 一级达成度（学生-课程目标达成度）

```
result_student_objective.achievement =
    Σ(学生考核点得分 / 考核点满分 × 关联权重) / Σ(关联权重)

其中：
- 考核点通过 rel_point_objective 表与课程目标关联
- 权重来自 rel_point_objective.weight（默认1.0）
- 结果保留4位小数
```

### 二级达成度（课程-指标点达成度）

```
result_course_indicator.course_achievement =
    Σ(学生课程目标达成度 × 内部权重) / Σ(内部权重)

其中：
- 内部权重来自 weight_objective_indicator.inner_weight
- 累加所有关联该指标的学生达成度
- 结果保留4位小数
```

## 🔗 表关联关系

```
学生成绩计算流程：

student_score (原始成绩)
    ↓
rel_point_objective (考核点↔课程目标关联 + 权重)
    ↓
result_student_objective (一级达成度：学生-课程目标)
    ↓
weight_objective_indicator (课程目标↔指标点权重)
    ↓
result_course_indicator (二级达成度：课程-指标点)
```
