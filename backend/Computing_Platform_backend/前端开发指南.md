# 前端开发指南

本文档基于后端 `BaseResponse` 和 `ErrorCode` 规范，为前端开发人员提供接口对接注意事项。

---

## 一、统一响应格式 (BaseResponse)

所有接口返回均为 JSON 格式，遵循 `BaseResponse` 结构：

```typescript
interface BaseResponse<T> {
  code: number;      // 业务状态码
  data: T;           // 响应数据
  message: string;   // 提示信息
}
```

### 关键点：
- `code = 0` 表示成功
- `data` 可能是任何类型（对象、数组、分页结果等）
- 成功时 `message` 通常为 `"ok"`

### 响应示例：

**成功响应：**
```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "admin"
  },
  "message": "ok"
}
```

**失败响应：**
```json
{
  "code": 40000,
  "data": null,
  "message": "请求参数错误"
}
```

## 二、错误码规范 (ErrorCode)

| code | 说明 | 处理建议 |
|------|------|----------|
| 0 | 成功 | 正常处理数据 |
| 40000 | 请求参数错误 | 检查请求参数格式和必填项 |
| 40100 | 未登录 | 跳转登录页 |
| 40101 | 无权限 | 提示权限不足 |
| 40400 | 请求数据不存在 | 提示数据不存在 |
| 40300 | 禁止访问 | 提示账号已被禁用 |
| 50000 | 系统内部异常 | 提示系统错误，联系管理员 |
| 50001 | 操作失败 | 提示操作失败 |

### 建议封装统一错误处理：

```javascript
function handleResponse(response) {
  if (response.code !== 0) {
    switch (response.code) {
      case 40100:
        // 跳转登录页
        router.push('/login');
        break;
      case 40101:
      case 40300:
        // 权限提示
        Message.error(response.message || '无权限操作');
        break;
      default:
        Message.error(response.message || '请求失败');
    }
    return false;
  }
  return true;
}
```

## 三、JWT 认证机制

### Token 传递方式：

**1. 请求头方式（推荐）：**
```javascript
headers: {
  'Authorization': 'Bearer ' + token
}
```

**2. URL 参数方式（备用）：**
```javascript
// ?token=xxx
axios.get('/api/xxx?token=' + token)
```

### 认证流程：

1. **登录获取 Token：**
   ```javascript
   // POST /sysuser/login/token
   {
     "username": "admin",
     "password": "123456"
   }
   ```

2. **缓存 Token：**
   ```javascript
   // 登录成功后存储
   localStorage.setItem('token', response.data.token);
   ```

3. **请求携带 Token：**
   ```javascript
   // axios 拦截器
   axios.interceptors.request.use(config => {
     const token = localStorage.getItem('token');
     if (token) {
       config.headers.Authorization = 'Bearer ' + token;
     }
     return config;
   });
   ```

4. **Token 失效处理：**
   - 返回 `40100` 时清除本地 Token
   - 跳转登录页重新登录

| 角色 | roleCode | 说明 |
|------|----------|------|

### 白名单（无需认证）：

### 用户信息获取：

## 五、分页查询规范

### 分页响应结构 (PageResultVO)：

```typescript
interface PageResultVO<T> {
  records: T[];    // 当前页数据列表
  total: number;   // 总记录数
  size: number;    // 每页条数
  current: number; // 当前页码
  pages: number;   // 总页数
}
```

### 分页请求示例：

```javascript
// POST /course/page
{
  "current": 1,        // 当前页码（从1开始）
  "size": 10,          // 每页条数
  "courseName": "",    // 其他查询条件...
  "collegeId": null
}
```

### 响应示例：

```json
{
  "code": 0,
  "data": {
    "records": [...],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  },
  "message": "ok"
}
```

## 六、文件上传/下载

### 文件上传：

```javascript
const formData = new FormData();
formData.append('file', file);

axios.post('/course/import/excel', formData, {
  headers: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'multipart/form-data'
  }
});
```

### 文件下载（模板下载）：

```javascript
axios.get('/course/template', {
  responseType: 'blob',
  headers: {
    'Authorization': 'Bearer ' + token
  }
}).then(response => {
  // 创建下载链接
  const url = window.URL.createObjectURL(new Blob([response.data]));
  const link = document.createElement('a');
  link.href = url;
  link.setAttribute('download', '课程导入模板.xlsx');
  document.body.appendChild(link);
  link.click();
});
```

## 七、接口调用建议

### 1. 统一封装 axios 拦截器

```javascript
import axios from 'axios';

const service = axios.create({
  baseURL: '/api',
  timeout: 10000
});

// 请求拦截器
service.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = 'Bearer ' + token;
    }
    return config;
  },
  error => Promise.reject(error)
);

// 响应拦截器
service.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code !== 0) {
      // 处理错误
      handleError(res);
      return Promise.reject(res);
    }
    return res;
  },
  error => {
    // 处理网络错误
    return Promise.reject(error);
  }
);

export default service;
```

### 2. 登录状态管理

- 使用 localStorage/Vuex/Pinia 存储 token
- 40100 错误时自动清除并跳转登录
- 页面刷新时从 localStorage 恢复登录状态

### 3. 请求 Content-Type

| 请求类型 | Content-Type |
|----------|--------------|
| 普通 JSON 请求 | `application/json` |
| 文件上传 | `multipart/form-data` |

### 4. ID 参数传递

部分接口使用 `DeleteRequest` 包装 ID：

```json
{
  "id": 123
}
```

例如：`POST /course/get`、`POST /course/delete`

## 八、常见问题

### Q1: 为什么有的接口用 GET，有的用 POST？

A: 查询类接口如果有查询条件，通常使用 POST（便于传递复杂对象）；简单查询可能使用 GET。

### Q2: Token 过期时间是多少？

A: 请咨询后端开发人员，根据 JWT 配置而定。

### Q3: 如何判断用户权限？

A: 登录成功后返回的用户信息中包含 `roleCode` 字段，前端可根据此字段控制界面显示。

### Q4: 分页从第几页开始？

A: 分页从 `current = 1` 开始（不是0）。
